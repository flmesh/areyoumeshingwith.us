Types of Hardware for Meshtastic and Meshcore Systems.

<!--more-->
So one of the most freqent questions I get ask from new users is "*What hardware should I get for my first node?*" 

### ESP32
* ESP32 are simple to use, easy to flash and work with, along with having both wifi and BT

### NRF52
* NRF52 Far better power effecincy then ESP32 but has a more complicated flashing system.
* Uses a Bootloader and needs to be mounted like a portable storage device to be able to have new firmware added on. 
* Doesn't have Wifi but does have BT
